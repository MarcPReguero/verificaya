# Sistema de Precios Dual: Suscripción + Pago por Uso

## 🎯 Estrategia de Pricing

### Filosofía
Ofrecer **flexibilidad máxima** adaptándonos a diferentes perfiles de clientes:
- **Propietarios ocasionales:** Pago por uso
- **Propietarios profesionales:** Suscripción mensual con ahorro significativo

---

## 💳 OPCIÓN 1: Pago por Informe (Pay-as-you-go)

### Básica - €59 por informe
**Target:** Primera vez, uso ocasional (1-2 verificaciones/año)

**Incluye:**
- ✓ Verificación de identidad (NIE/DNI/Pasaporte)
- ✓ Comprobación de ingresos netos
- ✓ Historial de empleo
- ✓ Informe PDF completo en 24h
- ✓ Soporte por email

**Casos de uso:**
- Propietario privado con 1 propiedad
- Verificación puntual
- Prueba del servicio

**Precio antiguo:** €49 → **Nuevo:** €59 (+€10, +20%)
**Razón:** Alineado con mercado premium, mejor valor percibido

---

### Completa - €99 por informe
**Target:** Propiedades de alto valor, inquilinos complejos

**Incluye:**
- ✓ Todo lo del plan Básico
- ✓ Consulta de solvencia/crédito
- ✓ Referencias de propietarios anteriores
- ✓ Verificación exhaustiva de documentos
- ✓ Informe PDF completo en **12h** (más rápido)
- ✓ Soporte prioritario

**Casos de uso:**
- Renta >€1,200/mes
- Propiedades premium
- Inquilinos internacionales
- Situaciones complejas

**Precio antiguo:** €89 → **Nuevo:** €99 (+€10, +11%)
**Razón:** Mejor margen, servicio premium justifica el precio

## 💡 Estrategia de Pricing

### Precios Psicológicos

**€59 vs €60:**
- Percepción "bajo €60"
- Parece significativamente menos

**€99 vs €100:**
- Precio premium justificado
- "Casi €100" pero psicológicamente menor

**€49/mes vs €50/mes:**
- "Menos de €50" es un threshold importante
- Precio ancla muy competitivo

**€129/mes vs €130/mes:**
- Precio medio óptimo
- €1,548/año parece más accesible

**€299/mes vs €300/mes:**
- Precio enterprise
- €3,588/año es significativo pero justificado

### Anclas de Precio

1. **Ancla Alta:** Pay-per-use a €99
   - Hace que suscripción parezca muy barata
   - €12.90/verificación vs €99 = 87% descuento

2. **Ancla Media:** Professional a €129
   - Marcado como "MÁS POPULAR"
   - Balance perfecto precio/valor

3. **Ancla Baja:** Starter a €49
   - Entrada accesible
   - Engancha clientes, luego upgrade

### Upselling Path

```
Pay-per-use (€99)
    ↓
Starter (€49/mes) → "Ahorra €248"
    ↓
Professional (€129/mes) → "10x capacidad, solo +€80"
    ↓
Enterprise (€299/mes) → "30x capacidad, solo +€170"
```

## 🚀 Implementación Técnica

### Base de Datos
```sql
-- Tabla de suscripciones
CREATE TABLE subscriptions (
  id UUID PRIMARY KEY,
  landlord_id UUID REFERENCES landlords(id),
  plan VARCHAR(20), -- starter, professional, enterprise
  status VARCHAR(20), -- trial, active, cancelled, expired
  current_period_start TIMESTAMP,
  current_period_end TIMESTAMP,
  screenings_used INT DEFAULT 0,
  screenings_limit INT,
  stripe_subscription_id VARCHAR(255),
  created_at TIMESTAMP DEFAULT NOW()
);

-- Tracking de uso
CREATE TABLE screening_usage (
  id UUID PRIMARY KEY,
  subscription_id UUID REFERENCES subscriptions(id),
  screening_id UUID REFERENCES screenings(id),
  counted BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMP DEFAULT NOW()
);
```

### Stripe Integration

**Pay-per-use:**
```typescript
stripe.checkout.sessions.create({
  mode: 'payment',
  line_items: [{
    price: 'price_basic_59' / 'price_complete_99',
    quantity: 1,
  }],
});
```

**Suscripción:**
```typescript
stripe.checkout.sessions.create({
  mode: 'subscription',
  line_items: [{
    price: 'price_starter_49' / 'price_pro_129' / 'price_enterprise_299',
    quantity: 1,
  }],
  subscription_data: {
    trial_period_days: 7,
  },
});
```
